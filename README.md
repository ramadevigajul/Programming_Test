# Java Practice Programs

## 📌 Description
This repository contains Java programs created as part of a programming test submission. It includes basic problem-solving programs using core Java concepts.

## 📂 Folder Structure
- PracticeTest/
  - src/
    - Series.java
    - Pattern.java
    - PrimeNumber.java
    - Duplicate.java
    - SumOfArrayElement.java

## 💻 Programs Included

1. GenerateSeries  
   - Generates number series based on logic

2. PatternPrinting  
   - Prints different patterns using loops

3. PrimeNumber  
   - Checks whether a number is prime

4. SecondDuplicate  
   - Finds the second duplicate character in a string

5. SumOfSmallestNum  
   - Finds sum of smallest numbers in array

## 🛠️ Technologies Used
- Java
- Eclipse IDE

## ▶️ How to Run
1. Open project in Eclipse or any Java IDE  
2. Navigate to src folder  
3. Run the desired .java file
